# Call Reminder Cards

A simple and user-friendly website for managing people who need to be contacted. Each person is displayed as a card containing important information about the call.

## 📌 About the Project

This website helps users keep track of people they need to call. Instead of keeping names and call details in notes, the user can store everything in organized cards.

Each card contains:

* **Name** — Name of the person who needs to be called
* **Hometown** — The person's hometown
* **Purpose of Call** — Why the person needs to be contacted
* **Priority** — Importance of the call

### 🚨 Priority Levels

The website supports three priority levels:

* 🔴 **Emergency** — Needs immediate attention
* 🟠 **Urgent** — Should be called soon
* 🟢 **No Rush** — Can be called later
* 🔴 **Important** — Needs immediate attention

## ✨ Features

* Add a new person's details
* Display each person in a separate card
* Show the person's name, hometown, and purpose of the call
* Assign a priority to each call
* Easily identify important calls through priority labels
* Search/filter cards
* Delete cards when a call is no longer required
* Store data using **Local Storage** so the information remains available after refreshing the page

## 🛠️ Technologies Used

* **HTML** — Website structure
* **CSS** — Styling and card layout
* **JavaScript** — Adding, removing, searching, and managing cards
* **Local Storage** — Saving call information in the browser

## 🚀 How to Use

1. Open the website.
2. Add the person's name.
3. Enter their hometown.
4. Enter the purpose of the call.
5. Select the priority:

   * Emergency
   * Urgent
   * No Rush
6. Add the person.
7. The information will appear as a card.
8. Use the card to keep track of the calls that need to be made.

## 🎯 Project Goal

The main goal of this project is to create a simple **call-management system** that allows users to organize important calls and quickly understand which calls require immediate attention.
